Markup

API

Class / attributeDescription
html[data-theme="light|dark|auto"]Colour mode. data-theme-resolved (set by JS) is the actual mode the CSS keys off; without JS the page is dark.
html[data-accent="green|cyan|blue|violet|magenta|red|orange|yellow"]Accent preset. custom is set by MGLSK.setAccent("#hex").
MGLSK.setTheme(mode)Switch mode; persisted in localStorage["mglsk-theme"]; fires mglsk:theme.
MGLSK.setAccent(nameOrHex)Preset or custom colour; persisted in mglsk-accent; fires mglsk:accent. Custom colours are lightened/darkened until they reach 4.5:1 against the dark and light surfaces.
MGLSK.contrast(hexA, hexB)WCAG contrast ratio helper.
[data-theme-set] / [data-theme-toggle] / [data-accent-set] / input[data-accent-custom]Declarative controls; state mirrored in aria-pressed. Wrap a popup in data-keep-open so clicks inside do not close the dropdown.
--accent-rgbTriplet r g b for the current mode — use rgb(var(--accent-rgb) / .2) for tints and glows. Also --accent, --accent-soft, --accent-deep, --accent-hover, --on-accent (text colour for accent fills).
Neutrals & status--bg --surface --surface-2 --surface-3 --border --border-strong --text --muted --faint; --success --warning --danger --info with -soft tints; chart series --s1…--s6 (--s1 follows the accent).
<head> snippetAdd the small inline script from tools/docs/theme_ui.py (EARLY) before the stylesheet paints to avoid a flash of the wrong theme. Every page in this kit already has it.
EffectsThe WebGL dot field and particle logo read the theme: green glow on dark, ink-on-light in light mode, accent-coloured highlights.
