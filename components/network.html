Network_

// Isometric node graph: cubes on a floor grid joined by animated data links. Hover or focus a node to light up its neighbours.

Data display

Preview

Select a node.

Markup

API

Class / attributeDescription
MGLSK.charts.network(el, {nodes, links, title, height, routing})Renders the graph. routing is "ortho" (default, links follow the grid axes) or "straight". colors maps a group to a colour slot 1–6 (default: order of first appearance). Height is automatic unless you pass height.
nodes[]{id, label, x, y, z, group, status, size} — x/y are floor-grid cells, z lifts a node onto a floating layer, group picks the colour (--s1…--s6), status is ok|warn|danger, size scales the cube.
links[]{from, to, status} — status: "down" draws a red dashed link with no traffic.
mglsk:networkFired on the host when a node is clicked or activated with Enter/Space: detail = {id, node, selected}.
AccessibilityNodes are focusable buttons named with group, status and connection count; a visually-hidden table lists every node and link.
MotionLink traffic is a CSS animation: it stops with prefers-reduced-motion and the CRT toggle.
